TABLE knowledge_chunks	платформа называет столбец привязки scope, у Прагматики был supplier_id
INDEX knowledge_chunks_supplier_idx	в платформе индекс по привязке называется knowledge_chunks_scope_idx
INDEX knowledge_chunks_scope_idx	платформенное имя индекса по столбцу scope (у Прагматики supplier_idx)
FUNCTION hybrid_search(text, public.vector, integer, text, text, integer, integer, integer, double precision)	платформенная редакция: параметр filter_scope, столбец scope, иные комментарии в теле
FUNCTION knowledge_fts_query(text)	платформенная редакция: STABLE вместо IMMUTABLE, комментарии тела без слов предметной области
FUNCTION hybrid_search_suppliers(text, public.vector, integer, integer, integer, integer, double precision)	предметная функция читает столбец scope (app/026) вместо supplier_id
